Volatility 3 is the world's most widely used framework for extracting digital artifacts from volatile memory (RAM) samples. Built as a complete rewrite, it delivers a clean plugin architecture, automatic symbol table resolution, and a powerful Python library that can be embedded in your own tools and workflows.

## What you can do with Volatility 3

Volatility 3 analyzes memory images from live systems or memory acquisition tools. You can investigate running processes, network connections, loaded drivers, registry keys, and much more — all without running code on the target system.

## How it works

<Steps>
  <Step title="Acquire a memory image">
    Use a tool like WinPmem, LiME, or AVML to capture a RAM dump from your target system.
  </Step>
  <Step title="Run a plugin">
    Point Volatility at the image and choose a plugin. Automagic handles layer stacking and symbol resolution automatically.
    ```bash
    vol -f memory.raw windows.pslist
    ```
  </Step>
  <Step title="Analyze the output">
    Results are rendered as a table, JSON, CSV, or SQLite — or consumed programmatically via the Python library API.
  </Step>
  <Step title="Extend with custom plugins">
    Write your own analysis plugins by inheriting from `PluginInterface` and defining requirements and a `run()` method.
  </Step>
</Steps>

## Use as a library

Volatility 3 is designed to be embedded. Import it into your Python application to build custom forensics pipelines, automated triage tools, or SIEM integrations.

```python
import volatility3.plugins
from volatility3 import framework
from volatility3.framework import contexts, automagic, plugins

framework.require_interface_version(2, 0, 0)
ctx = contexts.Context()
# ... configure and run plugins programmatically
```
